# 🚀 DataSense AI – PostgreSQL Business Intelligence

DataSense AI is an AI-powered Business Intelligence application developed using **Python, Streamlit, and PostgreSQL**. It enables users to explore company data by asking questions in natural language instead of manually writing SQL queries.

The application combines AI-assisted SQL generation, database exploration, interactive business dashboards, employee and department management, data visualization, and downloadable reports in one platform.

**Example:** Ask "How many employees are in each department?" and DataSense AI can generate a PostgreSQL query and display the results.

---

## ✨ Features

### 1. AI-Powered SQL Assistant
- Converts natural-language questions into PostgreSQL queries.
- Supports Google Gemini and Groq as AI providers.
- Displays generated SQL queries and execution results.
- Attempts to repair generated queries when execution fails.
- Handles supported explanatory questions about SQL and database concepts.

### 2. Read-Only Analytical Query Execution
- Restricts AI-generated analytical queries to supported read-only SQL statements, including SELECT queries and read-only CTEs.
- Uses read-only transactions and statement timeouts during query execution.
- Separates AI-generated analytical queries from database-management operations.

### 3. Business Intelligence Dashboard
- Displays total employee and department counts.
- Shows salary-related business metrics.
- Provides department-wise employee distribution and salary visualizations.

### 4. Database Explorer
- Lists tables available in the PostgreSQL public schema.
- Allows users to inspect and search database records.
- Supports CSV and Excel exports.

### 5. Employee Management
- View, search, and filter employee records.
- Add new employee records.
- Update existing employee information.
- Delete employee records.

### 6. Department Management
- View department information.
- Add new departments.

### 7. Query History and Reports
- Maintains AI query history for the current application session.
- Allows users to download query results in CSV and Excel formats.
- Provides visualization options for supported query results.

## 📋 Prerequisites

Before installing the application, make sure you have:

1. Python 3.10 or newer.
2. PostgreSQL installed and running.
3. A PostgreSQL account with permission to create the project database when using `setup_db.py`.
4. An API key for at least one supported AI provider if you want to use AI features:
   - Google Gemini API key (`GOOGLE_API_KEY`).
   - Groq API key (`GROQ_API_KEY`).

**Requirements:**
- A working PostgreSQL connection is required for the dashboard and database-management features.
- At least one configured AI provider is required for AI-assisted SQL generation and explanations.
- A Groq API key is required for voice transcription.

## ⚙️ Installation and Setup

Follow these steps to install and run DataSense AI locally.

### 1. Clone the Repository

Open your terminal and execute:

```bash
git clone https://github.com/Taiz371/datasense-ai.git
cd datasense-ai
```

### 2. Create and Activate a Virtual Environment

**Windows PowerShell:**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Dependencies

Upgrade pip and install the required packages:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Create a file named `.env` in the project root directory, alongside `app.py` and `setup_db.py`.

Add the following configuration:

```env
DB_USER=postgres
DB_PASSWORD=your_postgres_password
DB_HOST=localhost
DB_PORT=5432
DB_NAME=company_db

GOOGLE_API_KEY=your_gemini_api_key
GROQ_API_KEY=your_groq_api_key
```

Replace the example values with your actual PostgreSQL credentials and API keys.

**Important:**
- Configure at least one AI provider API key to enable AI functionality.
- Never upload your `.env` file to GitHub.
- Never expose database passwords or API keys publicly.
- If the application provides sidebar credential inputs, use them as supported by the application.

### 5. Create and Initialize the Database

Ensure that PostgreSQL is running, then execute:

```bash
python setup_db.py
```

The database setup script is designed to:
- Create the configured database if it does not exist.
- Create the `departments` and `employees` tables.
- Insert sample company data.

Use a PostgreSQL account with the required database and table permissions.

### 6. Run the Streamlit Application

Start the application using:

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal.

Usually:

http://localhost:8501

## 💡 How to Use the Application

1. Start the application using `streamlit run app.py`.
2. Open the Streamlit application in your browser.
3. Configure your PostgreSQL connection details in the sidebar if prompted.
4. Configure at least one supported AI provider API key.
5. Verify that the PostgreSQL database connection is successful.
6. Open the AI SQL Assistant.
7. Enter a question in natural language.
8. Review the generated SQL query and its results.
9. Explore the Dashboard, Data Explorer, Employees, Departments, and Query History sections.
10. Download query results in CSV or Excel format where available.

## 🔒 Security and Important Notes

- Keep `.env`, database passwords, and API keys out of Git commits.
- AI-generated analytical queries are designed for read-only execution.
- Employee and department management features intentionally perform database write operations.
- Changes made through management pages may be committed immediately.
- Back up important database information before testing write operations.
- Use a development or demonstration database rather than a production database.
- Salary metrics are calculated from stored salary values; the application does not automatically infer a pay period.
- AI features depend on valid API keys, provider availability, and internet connectivity.

## 🛠️ Troubleshooting

### PostgreSQL Connection Failed

- Ensure PostgreSQL is running.
- Verify `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT`, and `DB_NAME`.
- Check that the database user has the required permissions.

### Database Does Not Exist

Run the database setup script:

```bash
python setup_db.py
```

Ensure that the configured PostgreSQL account has permission to create databases.

### No Tables Found

- Confirm that `setup_db.py` completed successfully.
- Verify that the application connects to the correct database.
- Check whether the `employees` and `departments` tables exist.

### AI Features Are Unavailable

- Verify that at least one provider API key is configured correctly.
- Check your internet connection.
- Verify API key validity, provider availability, and usage quota.

### Python Module Is Missing

Activate the project's virtual environment and execute:

```bash
pip install -r requirements.txt
```
